# MALBIT product design north star

## 무엇을 만드는가

MALBIT는 일본어 설명을 우선 제공하는 한국어 완전 초보자가 게임과 이야기를 따라가며
한국어를 익히고, 이후 TOPIK I·II 실전 학습까지 자연스럽게 확장하는 모바일 우선 학습
PWA다.

장기적으로는 서울을 돌아다니며 한국어를 실제 상황처럼 사용하는 학습 RPG로 확장한다.
학습이 게임을 방해하는 시험지가 아니라, 새로운 장소·퀘스트·캐릭터 보상을 여는 행동이
되어야 한다.

## 첫 핵심 사용자

- 한국어를 거의 읽지 못하는 완전 초보자
- 첫 설명 언어는 일본어
- 시험 점수만이 아니라 재미와 짧은 성취 때문에 다시 방문하는 사용자

## 첫 10분 약속

사용자는 긴 설정이나 레벨 검사 없이 게임·스토리 첫 단계를 끝낸다. 그 과정에서 적어도
하나의 한국어 표현을 보고, 듣고, 선택하고, 성공 보상과 다음 목표를 이해한다.

## 제품 우선순위

1. 재미·재방문·시장 경쟁력
2. 정답·해설·번역의 정확성
3. 실제 모바일 화면·터치 조작 품질
4. 초보에서 TOPIK 실전으로 이어지는 확장성
5. 혼자 운영해도 검수·배포·되돌리기가 가능한 단순한 구조

정확성은 다른 항목과 교환하지 않는다. 재미있는 오답 제조기는 학습 앱이 아니라 화려한
거짓말 기계다.

## 핵심 경험

- 게임 아래 독립된 Story Mode와 Wordlight Expedition
- 짧게 반복하는 Shorts와 Random Practice
- 틀린 문제와 단어를 다시 만나게 하는 Review·Vocabulary
- 실제 시험을 준비하는 전체 모의고사
- 일본어 초보 설명, 자연스러운 한국어 듣기, 읽기·쓰기·말하기로 확장 가능한 구조

## 서울 학습 RPG 방향

서울맵은 장식용 메뉴가 아니라 학습과 재방문을 연결하는 장기 메타게임이다.

1. 사용자가 오늘의 5~10분 학습 미션을 완료한다.
2. 서울의 장소 또는 NPC 퀘스트가 열린다.
3. 편의점·지하철·카페·관광지 같은 상황에서 배운 표현을 다시 사용한다.
4. 정답과 복습으로 재화·의상 조각·지역 평판을 얻는다.
5. 아바타를 꾸미거나 다음 장소를 열고, 다음 날 이어지는 퀘스트를 확인한다.

지도는 처음부터 서울 전체를 만들지 않는다. 한 개 지역, 짧은 이동, NPC 3명 이하,
학습 퀘스트 하나, 무료 꾸미기 보상 하나로 vertical slice를 먼저 검증한다. 이 작은 구간에서
첫 퀘스트 완료율과 다음 날 재방문이 오르지 않으면 도시 규모를 늘리지 않는다.

탐험은 제품의 본체가 아니라 공부를 지속시키는 보상 장치다. 문제를 풀지 않고 지도만
소비하거나, 지도 때문에 정답·해설·복습이 약해지는 구조는 만들지 않는다.

## 아바타·결제 보류 원칙

아바타는 현재 학습 성취를 눈에 보이게 만드는 **보상 장치**다. 수익화 장치가 아니다.

- 모든 기본 의상, 지역 기념품, 색상 변형, 헤어, 액세서리, 감정표현은 당분간 학습과
  퀘스트 보상으로만 얻는다.
- 앱 어디에도 결제 버튼, 가격, 상품 카드, 유료 잠금, Premium·Plus 배지, 구독 안내,
  업셀 팝업, 외부 결제 링크, 결제를 암시하는 비활성 상점을 만들지 않는다.
- 나중에 쓸 예정이라는 이유로 빈 결제 자리나 가짜 상품을 먼저 노출하지 않는다. 존재만으로
  사용자는 학습 경험이 판매를 위한 미끼라고 느낄 수 있다.
- 결제는 충분한 무료 가치와 신뢰가 증명된 마지막 단계까지 보류한다.
- 결제를 논의하는 별도 단계에서는 사용자 감정, 학습 성취 뒤의 자연스러운 시점, 판매할
  실제 가치, 가격, 노출 빈도, 거부 후 경험, 환불·되돌리기를 먼저 정한다.
- 그 논의와 사용자의 명시적 승인 전에는 결제 연구를 했더라도 같은 작업에서 구현하지 않는다.
- 조급함, 손실 공포, 연속 팝업, 인위적 기능 제한으로 결제를 압박하지 않는다.

현재 측정할 것은 첫 퀘스트 완료율, 다음 날·7일 재방문율, 무료 보상 획득률과 장착률이다.
결제 전환율은 결제 기능을 도입하기로 결정한 뒤에만 지표로 추가한다.

## 출시 경계

- 현재 자동 출시 대상: GitHub Pages PWA
- 다음 단계: 계정·동기화·서버형 AI 기능의 비용과 개인정보 설계. 결제 UX는 계속 보류
- 이후 단계: Android 내부 테스트, iOS TestFlight, 양대 스토어 정식 출시

스토어 자동 배포는 서명, 결제, 개인정보, 심사, 단계 배포, 긴급 중단과 되돌리기 절차가
준비된 뒤에만 연다.

## 절대 조건

- 기존 브라우저 진도와 단어장 기록을 잃지 않는다.
- 공개 클라이언트에 API 키나 비밀정보를 넣지 않는다.
- 2,088개 오리지널 문제은행을 복제 기출문제로 바꾸지 않는다.
- Story Mode를 전체 모의고사 안에 합치지 않는다.
- 로그인하지 않아도 핵심 학습 기능을 사용할 수 있다.
- 별도 수익화 논의와 사용자의 명시적 승인 전에는 어떤 결제 관련 UI도 추가하지 않는다.
