# MALBIT feedback inbox

휴대폰 지시는 GitHub Issue로 입력한다. 제목은 `[AI 지시]`로 시작하고 다음 틀을 사용한다.

```md
원하는 결과:
왜 필요한가:
직접 본 문제:
완료라고 판단할 기준:
```

긴급한 지시는 `[AI 지시][긴급]`으로 시작한다. 자동 작업을 건너뛰려면 `[AI 제어] PAUSE`
Issue를 열고, 다시 시작하려면 그 Issue를 닫는다.

이 파일은 Issue를 사용할 수 없을 때만 쓰는 예비 입력함이다. 아래에 새 지시를 한 줄씩
추가하되 비밀번호, API 키, 개인정보는 절대 기록하지 않는다.
