# Third-party notices

## Optional local AI voice pack

MALBIT can download and run Supertonic 3 speech models locally in the browser. The application
does not bundle the weights or send the learner's text to a speech server.

- Original model: [Supertone/supertonic-3](https://huggingface.co/Supertone/supertonic-3)
- Pinned FP16 conversion: [Kyumdroid/supertonic-3-quant](https://huggingface.co/Kyumdroid/supertonic-3-quant)
- Model license: BigScience Open RAIL-M, including its use restrictions
- Browser inference example: [supertone-inc/supertonic](https://github.com/supertone-inc/supertonic), MIT
- Runtime: [ONNX Runtime Web](https://github.com/microsoft/onnxruntime), MIT

The model and project names are attribution only and do not imply endorsement. Review the current
OpenRAIL-M terms and restricted uses before an app-store release or any change in product use.
