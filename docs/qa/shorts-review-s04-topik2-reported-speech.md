## Reviewed learning contract

Each card asks one quick communicative-function judgment about the sentence being reported:

- `-다고 하다`: report a statement or fact
- `-냐고 하다`: report a question
- `-(으)라고 하다`: report a command or request
- `-자고 하다`: report a suggestion to do something together

The four meanings are mutually distinct. Each reviewed example contains a decisive sentence-function cue,
so only one option fits. Selected-choice feedback explains the chosen function before optional full coaching
maps all four and gives one reusable original-sentence-function method. Fixed choices are shuffled and restored
through the existing Shorts record.
