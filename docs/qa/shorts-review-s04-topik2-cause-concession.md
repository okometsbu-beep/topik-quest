## Reviewed learning contract

Each card asks one quick judgment using the result's value and whether the condition is real or hypothetical:

- `-(으)ㄴ 탓에`: attributes a bad result or blame to the preceding cause
- `-(으)ㄴ 덕분에`: credits the preceding cause for a beneficial result
- `-는데도`: concedes an actual fact before an unexpected contrary result
- `-(으)ㄹ지라도`: concedes a hypothetical situation while retaining the following conclusion

The reviewed examples make the result value or reality decisive, so only one option fits. Each selected option
explains its own distinction before the optional full explanation maps all four and gives a reusable two-axis
method. Fixed reviewed choices are shuffled per card and restored from the existing Shorts record.
