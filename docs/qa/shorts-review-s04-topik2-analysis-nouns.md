## Reviewed learning contract

Each card asks one quick judgment about the role and time of an analytical noun:

- `경향`: a repeated pattern shared across cases or time
- `요인`: a cause or element affecting a result
- `현상`: an event or state that is actually observed
- `전망`: an expectation or judgment about a future state

The examples expose one decisive cue: a recent repeated increase, sleep affecting concentration,
visible droplets, or a next-year prediction. Selected-choice feedback explains the chosen function;
optional coaching compares all four. Fixed choices are shuffled and restored through the existing
stable-ID storage contract.
