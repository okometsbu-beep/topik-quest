## 원인과 변경

`haruman-intro.js`는 최초 실행부터 800ms 안에 playing이 오지 않으면 화면을
제거하고, 재생 위치와 관계없이 3380ms 뒤에 페이드를 시작했다.
따라서 지연 로딩/버퍼링/저속 재생에서는 ended 전에 화면이 사라질 수 있었다.
화면 터치·Escape·별도 버튼도 영상을 중단했으며, 60초 안에 새로고침하면 자동 생략했다.

- 정상 재생: 실제 `ended` → 220ms 페이드 → 미디어 해제 → 준비된 앱 표시.
- 수동 스킵 핸들러·버튼·버튼 CSS·공개 finish 함수와 최근 실행 자동 생략 제거.
- 백그라운드에서는 영상 일시정지와 감시 타이머 중지. 복귀하면 같은 위치에서 재생.
- 앱 초기화는 영상과 별개로 계속 진행. 모션 감소/데이터 절약 설정은 존중.
- 파일 오류·자동재생 거부 및 **재생 위치가 15초 연속 진행하지 않을 때**만 실패 복구.
  정상 timeupdate마다 전체 제한을 늘리는 방식이 아니라 실제 currentTime 증가를 확인한다.
- WebM 알파 검사/MP4 fallback 유지. 소스 교체 또는 백그라운드 일시정지로 발생한
  이전 play 요청의 늦은 거부가 새 재생을 종료하지 않게 요청 식별자를 확인한다.
- 현재 배포된 540px/2.833초 영상 파일 자체는 바꾸지 않았다. 원본 재편집 작업은 아님.
  문항은행·로컬 학습 저장·모드·두 테마 불변. 버전만 배포 후보 v149로 동기화.
